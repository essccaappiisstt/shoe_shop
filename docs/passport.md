# 1. Название проекта Белорусская Обувная Фабрика (БОФ)

## 2. Проблема
Фабрика БОФ начала расширяться, и вести учет в письменном виде стало проблематично, у клиентов появилось желание покупать продукцию в электронном формате, просматривая все новинки обуви не выходя из дома.

## 3. Пользователи
клиент магазина — выбирает товар и оформляет заказ; продавец-консультант — ведёт каталог и остатки; администратор — управляет пользователями и правами; 

## 4. Цель проекта
Оптимизация работы сети магазинов, упрощение процесса покупки для покупателей

## 5. Метрики успеха

- время оформления заказа — < 3 минут;
- клиент находит товар через поиск/фильтры — за 4 кликов;
- остатки обновляются сразу после продажи, без ручного ввода.



## 6. Границы (что НЕ делаем)

не подключаем реальные платёжные шлюзы.
нет мобильного приложения; 
доставка курьером не моделируется — заказ выдаётся в магазине.

## 7. Риски
Не получается выполнить план по реализации метрик в указанный срок -> приоритезация задачи по повышению производительности сотрудников
